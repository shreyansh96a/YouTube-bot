# AI Content Creator Bot

A production-ready Telegram bot powered by Google Gemini AI for content creation.

## Features

### Content Generation
- 🎬 YouTube Script Generator
- 📌 Viral Title Generator
- 📄 SEO Description Generator
- 🏷️ Tags Generator
- 🖼️ Thumbnail Prompt Generator
- 🖼️ AI Image Prompt Generator
- 🎬 AI Video Prompt Generator
- 💬 Instagram Caption Generator
- #️⃣ Hashtag Generator
- 🌍 Hindi ↔ English Translation

### User Features
- 📊 Daily Usage Tracking
- 💎 Premium Subscription
- 🔗 Referral System
- 📜 History Tracking
- ❤️ Favorites Management
- 👤 Profile Management
- ⚙️ Settings

### Admin Features
- 🛡️ Admin Panel
- 📊 Analytics
- 📢 Broadcast
- 👤 User Management
- 💎 Premium Management
- 🚫 Ban/Unban System
- 🔄 Bot Restart
